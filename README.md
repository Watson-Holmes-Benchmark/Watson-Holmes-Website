# Watson & Holmes: A Benchmark for Naturalistic AI Reasoning

This repository contains the website for **Watson & Holmes: A Benchmark for Naturalistic AI Reasoning**.

Watson & Holmes is a benchmark designed to evaluate AI reasoning using incrementally presented narrative evidence, open-ended questions, and unconstrained natural-language responses.

The benchmark is adapted from the [*Watson & Holmes*](https://boardgamegeek.com/boardgame/182694/watson-and-holmes) detective tabletop game.
